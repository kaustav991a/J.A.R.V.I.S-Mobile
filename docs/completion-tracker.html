02

Provider effects that outlive their tree

An effect resolving after its test body corrupts the act environment, after which every later render returns an empty tree — no throw, no warning. It has cost six tests and is why the anti-duplicate wiring has none. Cancellation at the source, which the test file itself concluded was the real fix.

03

A crash says what it was

Today a crash restarts in silence. The JS half is catchable, persistable and shippable now; a native crash still needs a service and a build, and stays owed rather than quietly folded in. The record is derived — no chat text, no token — because a crash log is exactly what gets pasted into a chat window.
